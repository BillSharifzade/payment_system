АрхитектураArchitecture

Спроектирована как банк, написана на RustDesigned like a bank, written in Rust

ЯдроThe core

Деньги не создаются и не исчезаютMoney is never created or destroyed

  • Двойная запись. Каждая операция — проводки, которые в сумме дают ноль. Проверяет сама база данных.Double entry. Every operation is entries that sum to zero. The database itself enforces it.
  • Целые дирамы. Никаких float — копейка не «округлится» в никуда.Integer dirams. No floats — not a fraction gets rounded away.
  • Только добавление. Изменить или удалить проводку запрещено на уровне базы.Append-only. Changing or deleting an entry is refused by the database.
  • Ключ идемпотентности. Повтор запроса проводится ровно один раз.Idempotency keys. A retried request posts exactly once.
  • Непрерывная сверка. Каждую минуту, а не раз в сутки.Continuous reconciliation. Every minute, not once a night.

ОтказоустойчивостьResilience

Сервер упал — деньги на местеA server dies — the money stays

  • RPO 0: 41 сценарий отказа, 43 377 подтверждённых переводов — все на месте на каждом узле и в восстановленной копии.RPO 0: 41 failure scenarios, 43,377 acknowledged transfers — all present on every node and in a restored copy.
